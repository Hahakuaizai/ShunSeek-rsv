## 功能对照主表（v0.1.9 全量审计：原版 .NET HEAD e7deb97 ↔ Rust v0.1.9）

审计口径（2026-11-25，用户发布门槛）：逐功能对照，三类分清——
**✅ 已对齐**（行为等价；标「真机待验」的是 Windows 专属链，代码已落地、只能真机验）/
**◆ 有意差异**（对应用户裁决或平台近似，差异点写明）/ **✗ 缺失·待裁决**（未做，
原因写明，汇总在本表末尾的待裁决清单，不静默丢弃）。

### 1. 窗口与显隐

| 功能 | 结论 | 说明 |
| --- | --- | --- |
| 热键呼出/隐藏 | ◆ 有意差异 | 机制不同：原版 RegisterHotKey 真注册，Rust 用 GetAsyncKeyState 轮询（带自定义热键 + 冲突探测 + 推荐胶囊）；默认键已对齐：Ctrl+Alt+Space，取不到时按原版候选链回退 Ctrl+Shift+Q → Alt+Q（v0.1.8），用户改过的键永远优先 |
| 显示位置 | ✗ 缺失·待裁决 | 原版：鼠标所在屏工作区水平居中、顶 = 屏顶 + 屏高×14%。Rust：eframe 默认落位（屏幕居中附近），未做鼠标屏 + 14% 定位；可用 Win32 FFI（MonitorFromPoint + 工作区）在 show() 时发 OuterPosition 实现，待裁决 |
| 显示/隐藏动画 | ✗ 缺失·待裁决 | 原版淡入 130ms + 上移 8→0、隐藏淡出 90ms。egui 无窗口级 opacity/位移动画通路（viewport alpha 不可编程调节），内容层淡入只能做近似、与原版不是一物；维持硬切，待裁决 |
| 任务栏/层级 | ✅ 已对齐 | 进任务栏、非常驻顶层（v0.1.6 起） |
| 窗口尺寸 | ✅ 已对齐 | 默认 780×540、最小 600×400 |
| 顶部布局高度 | ◆ 用户裁决 | v0.1.10 用户对真机截图裁决「上面缩小、下面扩大」，覆盖原版令牌：书眉 46→约 36（标题 Serif 22→20、控制键 32×28）、搜索框 54→44、段间距 12/16/10/6→5/5/5/5，顶部固定区总高 167→131（780×540 常量和），省出高度全给内容区；首页提示语并入空状态、不再独占一行 |
| 无边框拉伸 | ✅ 已对齐 | v0.1.9：四边 8px + 四角 12px 命中区走 ViewportCommand::BeginResize 系统接管；原版 6px——Rust 取 8px 更易命中（微差异，有意） |
| 窗口拖动 | ✅ 已对齐 | v0.1.10 改输入状态手判（v0.1.9 的全窗 click_and_drag 背景层会抢走按钮的 click，真机「点不了」元凶，已整层删除）：每帧记录全部交互控件矩形，按下点不在任何控件上、位移满 4px 才 StartDrag；书眉拖动与双击空白最大化保留；Linux+openbox 实测：空白区拖动 (+50,+35)、书眉拖动 (+30,+24)、8px 边带拉伸宽 780→850（合成事件每步 10px、首步被 WM 锚点吃掉，实测值 = 期望 − 一步） |
| 最大化形态 | ✅ 已对齐 | 最大化按钮字形切换 Max/Restore；v0.1.9 起最大化圆角归零（原版口径） |
| 窗口控制按钮 | ◆ 有意差异 | 构成不同：原版 筛选/主题/最小化/最大化/关闭；Rust 主题/设置/最小化/最大化/关闭（筛选在工具栏圆点、设置另有页脚入口）——功能等价、位置有别 |
| 点 ✕ 关闭 | ◆ 用户裁决 | Rust：✕（及 WM_CLOSE/任务栏关闭）恒隐藏到托盘（2026-11-25 用户钉死，覆盖原版后来的「完整退出」改动）；唯一正常退出 = 托盘「退出」 |
| Esc 键链 | ✅ 已对齐 | 三段链：关筛选面板 → 清空查询回首页 → 隐藏（v0.1.8）；v0.1.9 起最前再加一段：先关自绘右键菜单/添加菜单 |
| 呼出时搜索框 | ✅ 已对齐 | v0.1.9：保留查询词 + 全选 + 聚焦（对齐原版；v0.1.8 前是清空，已改） |
| 单实例 | ✅ 已对齐 | 命名互斥 + 唤醒事件（v0.1.8）；v0.1.9 补 --from-restart 衔接（管理员重启的新进程等旧进程退出后接管） |
| 点外隐藏 | ✅ 机制对齐原版 | v0.1.10：失焦自动隐藏整套拆除（连同最小化互斥/恢复宽限期/指针守卫），换原版 GlobalClickWatcher 机制——clickwatch.rs 全局 WH_MOUSE_LL 钩子（专职线程、回调只取坐标+投递），全局按键落点在主窗+设置窗矩形之外才隐藏；窗内点击与焦点事件不参与；托盘菜单期间挂起。与原版差异仅在挂载点：原版只在托盘菜单打开期间挂钩子，Rust 侧主窗可见期间常驻（要达到同样的「点外即藏」体感）。Windows 链真机待验 |

### 16. 动画总表（时长 / 缓动）

未注明缓动的 WPF DoubleAnimation 均为线性（无 EasingFunction）；CubicEase EaseOut 只用在下面标出的三处。

| 动画 | 时长 | 缓动 / 备注 |
|---|---|---|
| 窗口显示 | Opacity 0→1 用 160ms；位移 Y 10→0 用 220ms | 位移 CubicEase EaseOut；不透明度线性 |
| 窗口隐藏 / 关闭退出 | Opacity →0 用 110ms；位移 Y →+6 用 110ms | 线性；淡完才真正 Hide/Shutdown |
| 主题切换过渡 | RootLayer Opacity 0.72→1 用 170ms | CubicEase EaseOut |

| 筛选面板打开 | Opacity 0→1 用 140ms；Scale 0.96→1 用 170ms | 缩放 CubicEase EaseOut，原点右上角 (1,0) |
| 更新 pill 出现 | Opacity 0→1 用 220ms | 线性 |
| 工具按钮悬停层 | 入 120ms / 出 180ms | 关闭按钮、设置按钮、pill 悬停层同此节奏 |
| 磁贴悬停层 | 入 140ms / 出 200ms | 内容缩放 1.03：入 160ms / 出 200ms |
